# Graphit – Etappe C (Zeichnung, Skizze, Navigationswürfel) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Zeichnung und Skizze bekommen das schwebende Graphit-Layout (Werkzeugfelder statt Leiste und Fenster, das Blatt füllt das ganze Fenster), und der Navigationswürfel wird ein 26-teiliger Würfel mit Home-Knopf, Hervorhebung der aktuellen Ansicht und auf die Flächen geklebter Beschriftung.

**Architecture:** `shell::layout` bekommt einen Modus (`Model`, `Drawing`, `Sketch`) und liefert modusabhängige Rechtecke; die Inhalte der Modusfelder zeichnen `drawing_view.rs` und `sketch_panel.rs` selbst als `egui::Area`s (damit ihre Tests ohne Shell weiterlaufen). Der Würfel bekommt eine eigene Geometrie in `planora-render` (26 Bereiche, Treffer, aktueller Bereich) und eine neue Darstellung in `viewport.rs`.

**Tech Stack:** Rust, egui/eframe 0.36 (Area, Order, Mesh-Text über Galley-Netze), wgpu; Tests im eigenen Harness (`egui::Context::run_ui`).

**Spec:** `docs/superpowers/specs/2026-10-16-graphit-oberflaeche-design.md` (§4 Zeichnung/Skizze, §5, §9 F2/F3/F4/F8, §10–§11); Vorschauen `docs/superpowers/specs/2026-10-16-graphit-oberflaeche-vorschau/` (`zeichnung-graphit.html`, `skizze-graphit.html`); Würfel-Wahl des Nutzers: Variante C in Größe B (Vorschau `wuerfel-varianten.html`, nicht im Repository; hier beschrieben). Plan 3 von 4; Etappe B ist gemergt (`69d1fbc`).
