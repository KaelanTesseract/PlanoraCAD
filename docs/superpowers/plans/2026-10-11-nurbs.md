**Goal:** Freie Flächen und Kurven (NURBS) im Kernel: eigene NURBS-Rechnung, `Curve::Nurbs`/`Surface::Nurbs`, Netz und Prüfung, Ellipsen und Splines aus Skizzen werden zu Körpern, numerische Schnitte und Boolesche Operationen mit freien Flächen.

**Architecture:** `planora-math` bekommt den Baustein `nurbs` (Knotenvektor, Kurve, Fläche, exakte Konstruktionen, Annäherung) ohne neue Abhängigkeit. Der Kernel bekommt zwei neue Enum-Varianten, die dieselben Grundfunktionen wie die analytischen Arten bieten (`point`, `tangent`, `project`, `implicit` als vorzeichenbehafteter Abstand, `normal`); dadurch läuft ein Großteil der bestehenden Booleschen Pipeline unverändert weiter. Skizzenprofile bekommen ein NURBS-Segment für Ellipse und Spline.

**Tech Stack:** Rust (Edition 2024), bestehende Crates; **keine neue externe Abhängigkeit** (`thiserror` ist bereits Workspace-Abhängigkeit und kommt in `planora-math` neu hinzu).

## Entscheidungen zur Spec (Planungsstand 2026-10-11)

Sie konkretisieren die Spec; Abweichungen sind begründet und werden am Ende in die Spec (Abschnitt „Änderungen bei der Umsetzung“) eingetragen.

- **Q1 – `implicit` für NURBS:** `Surface::implicit(p)` ist für NURBS der vorzeichenbehaftete Abstand zur Fläche (Vorzeichen nach der natürlichen Normale am Fußpunkt), berechnet über den nächsten Punkt (`closest_uv`). Dadurch funktionieren `curve_surface_roots` und alle Vorzeichenwechsel-Verfahren der Pipeline. Der nächste Punkt nutzt ein beim ersten Gebrauch aufgebautes Raster aus Stützpunkten (`OnceLock` in der Flächendaten-Struktur) und Newton-Nachbesserung.
- **Q2 – Keine Gradanhebung:** Die Spec nennt Gradanhebung; sie wird in diesem Teilprojekt nicht gebraucht (Loft/Sweep sind ausgenommen) und entfällt. Stattdessen gibt es Knoteneinfügen, Teilen und die **Zerlegung in rationale Bézier-Stücke**, die der Schnittrechner für Unterteilung und Hüllquader braucht.
- **Q3 – `Segment::Nurbs`:** Das Profilsegment des Kernels (`Segment`) bekommt `Nurbs { curve: Arc<NurbsCurve2> }`; `Segment` verliert dadurch `Copy` (bleibt `Clone`). Alle Stellen, die `Segment` kopieren, werden auf `Clone`/Verweise umgestellt.
- **Q4 – Schnittrechner steckt in `intersect_surfaces`:** Er liefert `SurfaceIntersection::Curves(vec![Curve::Nurbs(..)])` (je Schnittast eine NURBS-Kurve) beziehungsweise `Unsupported`/`Touch`/`Coincident` mit benannter Begründung. Die Pipeline (Haltepunkte, Teilen, Auswählen, Vernähen) arbeitet weiter über `Curve`-Funktionen.
- **Q5 – Benannte Grenzen:** `NURBS_FIT_TOL = 1e-5` (mm), `MAX_SUBDIVISION_DEPTH`, `MAX_SEEDS`, `MAX_MARCH_STEPS`, `MAX_CURVE_LENGTH_FACTOR`, `MAX_FIT_CONTROL_POINTS` – alle als `pub const` mit Kommentar im Modul `boolean::nurbs_ssi` bzw. `planora_math::nurbs`.
- **Q6 – Dateiformat:** Voraussichtlich bleibt Format 1 (die Zeitleiste enthält weiter nur Skizzen und Parameter; Skizzen-Splines sind schon Punktlisten). Task 12 prüft das und trägt das Ergebnis in die Spec ein; nur wenn ein neuer Zeitleisten-Parameter nötig wird, wird Format 2 angelegt.
- **Q7 – Nutzbare Grenzen für Eingaben:** `MAX_DEGREE = 9`, `MAX_CONTROL_POINTS = 4096` je Richtung und `262_144` insgesamt, Koordinaten höchstens `1e9` mm, Gewichte in `[1e-6, 1e6]`.

```rust
fn clamp_knots(p: usize, n: usize) -> Vec<f64> {
    // gleichmäßig geklemmt auf [0, 1]
    let mut k = vec![0.0; p + 1];
    let inner = n - p - 1;
    for i in 1..=inner {
        k.push(i as f64 / (inner + 1) as f64);
    }
    k.extend(std::iter::repeat_n(1.0, p + 1));
    k
}
```

```rust
use super::{MAX_DEGREE, NurbsError};

#[derive(Clone, Debug, PartialEq)]
pub struct KnotVector {
    degree: usize,
    knots: Vec<f64>,
}

impl KnotVector {
    /// Geklemmter Knotenvektor: die ersten und letzten `degree + 1` Knoten sind gleich.
    pub fn new(degree: usize, knots: Vec<f64>) -> Result<Self, NurbsError> {
        if degree == 0 || degree > MAX_DEGREE {
            return Err(NurbsError::Degree(degree));
        }
        if knots.len() < 2 * (degree + 1) {
            return Err(NurbsError::Knots("zu wenige Knoten".into()));
        }
        if knots.iter().any(|k| !k.is_finite()) {
            return Err(NurbsError::Knots("nicht endliche Zahl".into()));
        }
        if knots.windows(2).any(|w| w[1] < w[0]) {
            return Err(NurbsError::Knots("Knoten fallen".into()));
        }
        let (n, p) = (knots.len(), degree);
        let clamped = knots[..=p].iter().all(|k| *k == knots[0])
            && knots[n - p - 1..].iter().all(|k| *k == knots[n - 1]);
        if !clamped {
            return Err(NurbsError::Knots("nicht geklemmt (Anfang und Ende brauchen Grad+1 gleiche Knoten)".into()));
        }
        if knots[n - 1] <= knots[0] {
            return Err(NurbsError::Knots("der Parameterbereich ist leer".into()));
        }
        // Keine Mehrfachknoten über dem Grad im Inneren (sonst unstetig/entartet).
        let mut run = 1;
        for w in knots[p + 1..n - p - 1].windows(2) {
            run = if w[1] == w[0] { run + 1 } else { 1 };
            if run > p {
                return Err(NurbsError::Knots("innerer Knoten zu oft wiederholt".into()));
            }
        }
        Ok(KnotVector { degree, knots })
    }

    pub fn degree(&self) -> usize { self.degree }
    pub fn knots(&self) -> &[f64] { &self.knots }
    pub fn basis_count(&self) -> usize { self.knots.len() - self.degree - 1 }
    pub fn domain(&self) -> (f64, f64) { (self.knots[self.degree], self.knots[self.knots.len() - self.degree - 1]) }

    /// Index `i` mit `knots[i] <= u < knots[i+1]` (am rechten Rand der letzte nichtleere Abschnitt);
    /// `u` wird auf den Bereich begrenzt, ein nicht endliches `u` liefert den ersten Abschnitt.
    pub fn find_span(&self, u: f64) -> usize {
        let p = self.degree;
        let n = self.knots.len() - p - 2; // Index der letzten Basisfunktion
        if !u.is_finite() {
            return p;
        }
        let (a, b) = self.domain();
        let u = u.clamp(a, b);
        if u >= self.knots[n + 1] {
            return n;
        }
        let (mut lo, mut hi) = (p, n + 1);
        let mut mid = (lo + hi) / 2;
        while u < self.knots[mid] || u >= self.knots[mid + 1] {
            if u < self.knots[mid] { hi = mid } else { lo = mid }
            mid = (lo + hi) / 2;
        }
        mid
    }

    /// Die `degree + 1` nichtverschwindenden Basisfunktionen am Abschnitt `span` (A2.2).
    pub fn basis(&self, span: usize, u: f64) -> Vec<f64> {
        let p = self.degree;
        let mut n = vec![0.0; p + 1];
        let mut left = vec![0.0; p + 1];
        let mut right = vec![0.0; p + 1];
        n[0] = 1.0;
        for j in 1..=p {
            left[j] = u - self.knots[span + 1 - j];
            right[j] = self.knots[span + j] - u;
            let mut saved = 0.0;
            for r in 0..j {
                let den = right[r + 1] + left[j - r];
                let temp = if den != 0.0 { n[r] / den } else { 0.0 };
                n[r] = saved + right[r + 1] * temp;
                saved = left[j - r] * temp;
            }
            n[j] = saved;
        }
        n
    }

    /// Ableitungen der Basisfunktionen bis zur Ordnung `n` (A2.3); Zeilen jenseits des Grades sind 0.
    pub fn basis_derivs(&self, span: usize, u: f64, nd: usize) -> Vec<Vec<f64>> {
        let p = self.degree;
        let mut ders = vec![vec![0.0; p + 1]; nd + 1]; // Zeilen jenseits des Grades bleiben 0
        let k_max = nd.min(p);
        let mut ndu = vec![vec![0.0; p + 1]; p + 1];
        let mut left = vec![0.0; p + 1];
        let mut right = vec![0.0; p + 1];
        ndu[0][0] = 1.0;
        for j in 1..=p {
            left[j] = u - self.knots[span + 1 - j];
            right[j] = self.knots[span + j] - u;
            let mut saved = 0.0;
            for r in 0..j {
                ndu[j][r] = right[r + 1] + left[j - r];
                let temp = if ndu[j][r] != 0.0 { ndu[r][j - 1] / ndu[j][r] } else { 0.0 };
                ndu[r][j] = saved + right[r + 1] * temp;
                saved = left[j - r] * temp;
            }
            ndu[j][j] = saved;
        }
        for j in 0..=p {
            ders[0][j] = ndu[j][p];
        }
        let mut a = vec![vec![0.0; p + 1]; 2];
        for r in 0..=p {
            let (mut s1, mut s2) = (0usize, 1usize);
            a[0][0] = 1.0;
            for k in 1..=k_max {
                let mut d = 0.0;
                let rk = r as isize - k as isize;
                let pk = (p - k) as isize;
                if r >= k {
                    a[s2][0] = a[s1][0] / ndu[(pk + 1) as usize][rk as usize];
                    d = a[s2][0] * ndu[rk as usize][pk as usize];
                }
                let j1 = if rk >= -1 { 1 } else { (-rk) as usize };
                let j2 = if (r as isize - 1) <= pk { k - 1 } else { p - r };
                for j in j1..=j2 {
                    a[s2][j] = (a[s1][j] - a[s1][j - 1]) / ndu[(pk + 1) as usize][(rk + j as isize) as usize];
                    d += a[s2][j] * ndu[(rk + j as isize) as usize][pk as usize];
                }
                if r as isize <= pk {
                    a[s2][k] = -a[s1][k - 1] / ndu[(pk + 1) as usize][r];
                    d += a[s2][k] * ndu[r][pk as usize];
                }
                ders[k][r] = d;
                std::mem::swap(&mut s1, &mut s2);
            }
        }
        let mut f = p as f64;
        for k in 1..=k_max {
            for j in 0..=p {
                ders[k][j] *= f;
            }
            f *= (p - k) as f64;
        }
        ders
    }
}
```

Die beiden Funktionen sind die Standardalgorithmen A2.2 und A2.3 (Piegl/Tiller); der Code ist unkompiliert und darf zum Übersetzen angepasst werden. Die Tests oben prüfen beides gegen Differenzenquotienten und die Teilung der Eins.

`nurbs/curve.rs`: `NurbsCurve` nach den Regeln aus „Interfaces“; `derivs` über homogene Ableitungen (A4.2):

```rust
/// C^(k) = ( A^(k) − Σ_{i=1..k} binom(k,i) · w^(i) · C^(k−i) ) / w^(0), mit A = Σ N·w·P, w = Σ N·w.
pub fn derivs(&self, u: f64, n: usize) -> Vec<DVec3> {
    let p = self.knots.degree();
    let span = self.knots.find_span(u);
    let (a, b) = self.knots.domain();
    let u = if u.is_finite() { u.clamp(a, b) } else { a };
    let nd = self.knots.basis_derivs(span, u, n);
    let mut av = vec![DVec3::ZERO; n + 1];
    let mut wv = vec![0.0; n + 1];
    for k in 0..=n {
        for j in 0..=p {
            let i = span - p + j;
            let w = self.weights[i] * nd[k][j];
            av[k] += self.control[i] * w;
            wv[k] += w;
        }
    }
    let mut c = vec![DVec3::ZERO; n + 1];
    for k in 0..=n {
        let mut v = av[k];
        for i in 1..=k {
            v -= c[k - i] * (binom(k, i) * wv[i]);
        }
        c[k] = v / wv[0];
    }
    c
}
```

(`binom` ist eine kleine Hilfsfunktion für `k ≤ 4`.) `point(u) = derivs(u, 0)[0]`; `tangent(u) = derivs(u, 1)[1]`. `reversed`: Knoten `a + b − k` rückwärts, Punkte und Gewichte umgekehrt. `is_closed(tol)`: Abstand Anfang–Ende ≤ `tol`. `transformed(f)`: wendet `f` auf alle Kontrollpunkte an und baut mit `new` neu (so wird die Prüfung wiederholt).

```rust
/// Zylinder, dessen Mantel eine NURBS-Drehfläche (u = Winkel, v = Kurvenparameter 0..1) ist.
fn nurbs_cylinder_solid(r: f64, h: f64) -> Solid {
    let kernel = AnalyticKernel::default();
    let profile = Profile { outer: ProfileLoop::circle(DVec2::ZERO, r), holes: vec![] };
    let mut solid = kernel.extrude(&profile, &world(), h).unwrap();
    let line = NurbsCurve::new(1, vec![0.0, 0.0, 1.0, 1.0], vec![DVec3::new(r, 0.0, 0.0), DVec3::new(r, 0.0, h)], vec![1.0; 2]).unwrap();
    let nurbs = Surface::nurbs(NurbsSurface::revolve(&line, DVec3::ZERO, DVec3::Z, 0.0, TAU).unwrap(), true, false).unwrap();
    let ids: Vec<_> = solid.faces.iter().filter(|(_, f)| matches!(f.surface, Surface::Cylinder { .. })).map(|(id, _)| id).collect();
    assert_eq!(ids.len(), 1);
    solid.faces[ids[0]].surface = nurbs;
    solid.faces[ids[0]].patch = Some(UvRect { u0: 0.0, u1: TAU, v0: 0.0, v1: 1.0 });
    solid
}

#[test]
fn the_nurbs_cylinder_has_the_analytic_volume_and_area() {

    let mesh = tessellate(&solid, &opts(0.01)).unwrap();

    assert!((mp.volume - PI * r * r * h).abs() / (PI * r * r * h) < 2e-3, "{}", mp.volume);
    let area = TAU * r * h + 2.0 * PI * r * r;
    assert!((mp.surface_area - area).abs() / area < 2e-3, "{}", mp.surface_area);

}
```

  ```rust
  pub const MAX_MARCH_STEPS: usize = 20_000;       // Schritte je Verfolgung
  pub const MAX_CURVE_LENGTH_FACTOR: f64 = 20.0;   // größte Kurvenlänge = Faktor · Diagonale der Hüllquader beider Flächen
  pub enum SsiOutcome { Curves(Vec<Curve>), None, Touch, Coincident, Unsupported(String) }
  /// Schnitt zweier Flächen, von denen mindestens eine `Surface::Nurbs` ist.
  pub fn intersect_nurbs(a: &Surface, b: &Surface, tol: &Tolerance) -> SsiOutcome;
  ```
  `intersect_surfaces` (surfsurf.rs) ruft `intersect_nurbs`, sobald eine Seite NURBS ist, und bildet `SsiOutcome` auf `SurfaceIntersection` ab (`Unsupported(msg)` bekommt eine neue Variante `SurfaceIntersection::UnsupportedBecause(String)`; Aufrufer in `imprint.rs` verwenden den Text für `BooleanError::Unsupported`).

  **Verfahren (alles über vorzeichenbehaftete Abstandsfunktionen `F_a(q) = a.implicit(q)`, `F_b(q) = b.implicit(q)` mit Gradient = Einheitsnormale am Fußpunkt – gleich für analytische und NURBS-Flächen):**
  1. **Startpunkte.** NURBS-Seite(n) werden in Bézier-Flicken zerlegt (`bezier_patches`). *NURBS gegen NURBS:* Paare von Flicken mit überlappenden Hüllquadern werden rekursiv (je beide `subdivide`, Tiefe ≤ `MAX_SUBDIVISION_DEPTH`) verfolgt, bis beide `flatness() ≤ 0.05 · Diagonale` oder die Tiefe erreicht ist; überlappende flache Paare ergeben je einen Kandidaten (Mittelpunkt des Parameterbereichs). *NURBS gegen analytische Fläche:* ein Flicken ist Kandidat, wenn `F(Kontrollpunkte)` beide Vorzeichen hat oder der kleinste Betrag `≤ 0.25 · Flickendiagonale` ist (für die Ebene ist „alle Vorzeichen gleich“ ein sicherer Ausschluss); Unterteilung wie oben. Kandidaten werden durch **alternierende Projektion** auf beide Flächen (Newton im Raum: `q ← q − F·g/|g|²`, abwechselnd, höchstens 50 Schritte, Abbruch bei `|F_a|,|F_b| ≤ 1e-9·Maßstab`) zu Punkten der Schnittkurve; Duplikate (Abstand ≤ `1e-6`) und Punkte, die nicht konvergieren, werden verworfen. Mehr als `MAX_SEEDS` Startpunkte → `Unsupported("Zu viele Schnittbereiche …")`.
  2. **Verfolgen.** Tangente `t = (g_a × g_b)/|g_a × g_b|`; ist `|g_a × g_b| < 1e-4` am Startpunkt, so gilt der Punkt als tangentiale Berührung (`Touch` falls keine anderen Punkte, sonst Teil von `Unsupported("… berühren sich tangential")`). Schrittweite `h = clamp(√(8·NURBS_FIT_TOL/κ), h_min, h_max)` mit `κ` aus dem Winkel der letzten beiden Tangenten (am Anfang `h_max`), `h_max = Diagonale/200`, `h_min = 1e-4`. Vorhersage `p' = p + h·t`; Korrektur durch 3-D-Newton auf `F_a = 0, F_b = 0, t·(q − p') = 0` (Jacobimatrix aus `g_a, g_b, t`; Regularisierung bei fast paralleler Normalen: Abbruch der Verfolgung dieses Zweigs mit Hinweis). Verfolgt wird in beide Richtungen vom Startpunkt. **Ende:** (a) Rückkehr zum Anfang (`|q − start| < 1.5·h` bei mindestens 8 Schritten) → geschlossen, letzter Punkt = erster; (b) Verlassen des Parameterbereichs der NURBS-Fläche (Fußpunkt am Rand mit Restabstand > Toleranz) → Bisektion zwischen letztem gültigen und erstem ungültigen Punkt, bis der Randpunkt auf `1e-9` genau liegt; (c) Treffen auf einen schon verfolgten Zweig (Abstand zu dessen Polylinie `< 0.5·h`) → Zweige verbinden bzw. Verzweigung → `Unsupported("… verzweigt …")`; (d) `MAX_MARCH_STEPS` oder Länge `> MAX_CURVE_LENGTH_FACTOR · Diagonale` → `Unsupported("… zu lang …")`.
  3. **Ordnen.** Startpunkte, die auf schon verfolgten Zweigen liegen (Abstand `< 2h`), werden übersprungen; Zweige, deren Enden aneinanderliegen (`< 1e-6`), werden verbunden; geschlossene Schleifen bleiben geschlossen.
  4. **Annähern.** Jeder Zweig wird mit `NurbsCurve::fit(punkte, NURBS_FIT_TOL)` zu einer `Curve::Nurbs`; bei Fehlschlag `Unsupported("Die Schnittkurve lässt sich nicht annähern")`.
  5. **Sonderfälle.** *Zusammenfallend:* ≥ 90 % von 100 Stichproben der einen Fläche liegen innerhalb `tol.linear` auf der anderen (gegenseitig) → `Coincident`. *Berührung:* Kandidaten vorhanden, aber überall `|g_a × g_b| < 1e-4` und `F` wechselt das Vorzeichen nicht → `Touch`. *Kein Punkt:* `None`. Alle Rechnungen mit `f64`-Prüfung auf NaN (ein NaN bricht mit `Unsupported("Numerischer Fehler …")` ab, nie mit Panik).

```rust
fn nurbs_cylinder(axis_origin: DVec3, axis: DVec3, r: f64, h: f64) -> Surface {
    // Drehfläche einer zur Achse parallelen Linie
    let x = if axis.cross(DVec3::X).length() > 0.5 { DVec3::X } else { DVec3::Y };
    let radial = axis.cross(x).cross(axis).normalize();
    let line = NurbsCurve::new(1, vec![0.0, 0.0, 1.0, 1.0], vec![axis_origin + radial * r, axis_origin + radial * r + axis * h], vec![1.0; 2]).unwrap();
    Surface::nurbs(NurbsSurface::revolve(&line, axis_origin, axis, 0.0, TAU).unwrap(), true, false).unwrap()
}
```
