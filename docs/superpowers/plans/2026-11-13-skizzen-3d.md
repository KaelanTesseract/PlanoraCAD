# Skizzen 10: 3D-Skizze – Umsetzungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** In einer Skizze lässt sich wie in Autodesk Fusion mit Triade frei im Raum zeichnen. Dazu kommen 3D-Geometrie einbeziehen, Auf Fläche projizieren und Schnittkurve, und vorhandene Geometrie lässt sich aus der Ebene schieben.

**Architecture:**
- **Bauart B:** `PointData` bekommt `z: Option<usize>`, ebene Kurven außerhalb der Skizzenebene bekommen eine feste `normal: Option<DVec3>` in `CurveData`.
- **Löser:** Abhängigkeiten rechnen nur dann in einer 3D-Fassung (`Ctx::pt3`), wenn 3D-Geometrie beteiligt ist. Der 2D-Weg bleibt Zeile für Zeile, wie er ist.
- **Projektion:** Die neuen Projektionen sind weitere `CopySource`-Arten mit Stückindex, gerechnet in `planora-feature`.
- **Oberfläche:** Die App bekommt einen 3D-`Mapper`, die Triade (`sketch_triad.rs`) und zwei Dialoge.

**Tech Stack:** Rust, egui/eframe 0.36, wgpu. Keine neuen Abhängigkeiten.

**Spec:** `docs/superpowers/specs/2026-11-13-skizzen-3d-design.md`. Abschnitt 10 „Festlegungen nach der Prüfung“ geht vor. Jede Aufgabe liest die Spec mit.

## Review Focus

1. **Gemischte Skizze, 2D-Rechteck plus 3D-Linie an einer Ecke:** Das Rechteck bleibt ein Profil, solange die Ecke 2D ist. Erst „Deckungsgleich“ mit einem hochliegenden Punkt hebt die Ecke an, und dann verschwindet das Profil. Test in Task 3 und Task 6.
2. **Laden einer alten Datei und Speichern ohne Änderung:** Die Bytes sind gleich, auch wenn der Haken „3D-Skizze“ nie gesetzt war. Test in Task 7.
3. **Fast parallele Blickrichtung zur aktiven Triadenebene:** Kein Punkt im Unendlichen und keine Koordinaten über `MAX_COORD`. Test in Task 10.
4. **Projektion auf eine Fläche mit Loch (getrimmte Fläche):** Die Kurve wird am Lochrand geteilt und läuft nicht über das Loch. Test in Task 17.
5. **Körper ändert sich so, dass eine Projektion auf Fläche zwei statt eines Stücks ergibt:** Die alten Kurven bleiben, es gibt eine Warnung, und weder Absturz noch Rückgängig-Müll entstehen. Test in Task 18.
