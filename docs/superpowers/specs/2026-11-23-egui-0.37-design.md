# C13: egui 0.37 (Kurzentwurf)

Freigegeben von Dennis am 2026-11-23 („Ja, so bauen“).

## Warum

Offener Punkt C13. egui 0.37 bringt Fehlerbehebungen (Doppelklick als Dreifachklick, tote Zone am
Scrollbalken, Fokus an accesskit gefiltert) bei gleichem Unterbau: wgpu 30, winit 0.30, skrifa 0.44,
harfrust 0.12. skrifa 0.50 bleibt blockiert (epaint 0.37 verlangt skrifa ^0.44), ttf-parser wartet
weiter auf winit 0.31 (C14).

## Entwurf

1. eframe, egui, egui-wgpu auf 0.37; `rust-version` 1.88 → 1.95 (MSRV von egui 0.37).
2. Mechanischer Umbau ohne Verhaltensänderung: `Id::new` → `Id::unique` (gleiche Hashbildung),
   `Ui::id` → `Ui::scope_id`, `WidgetType` → `egui::Role`, Schrift-Schnittstelle (`Font` entfällt).
3. Fokus-Schutz `viewport::remember_keyboard_focus` prüfen: bleibt, wenn der Absturz ohne ihn wiederkommt,
   sonst entfernen.
4. deny-Hinweise zbus (RUSTSEC-2026-0370/0371/0372) neu prüfen (Regel bei jedem egui-Update).

## Verworfen

- Warten auf die nächste egui-Version: dann zusammen mit skrifa 0.50, größerer Sprung.
- Nur Warnungen abschalten: Altlast.

## Prüfung

Volle Läufe Windows und WSL, deny, Prüfer; Handtest nur nach Go (Bedienung, Fenster, Felder,
Doppelklick, Fokus).
