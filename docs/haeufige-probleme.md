# Häufige Probleme

## Windows zeigt beim ersten Start eine Warnung

Die Programmdatei ist nicht signiert. Darum kann Windows beim ersten Start eine blaue Warnung zeigen („SmartScreen“). Klick auf „Weitere Informationen“ und dann auf „Trotzdem ausführen“.

Die Prüfsumme, mit der das Programm Updates kontrolliert, schützt nur vor Fehlern bei der Übertragung. Lade das Programm deshalb nur von der [Seite der Veröffentlichungen](https://github.com/KaelanTesseract/PlanoraCAD/releases).

## Die 3D-Ansicht zeigt Fehler oder das Programm läuft nicht richtig

Aktualisiere den Treiber deiner Grafikkarte. Die Treiber gibt es bei den Herstellern der Karte. Starte das Programm danach neu. Hilft das nicht, melde es bitte (siehe [So meldest du etwas](so-meldest-du-etwas.md)). Schreib dazu, welche Grafikkarte du hast.

## Das Virenprogramm hält die Datei fest

Manche Virenprogramme prüfen eine neue Programmdatei erst eine Weile oder halten sie an. Warte, bis die Prüfung fertig ist, und starte das Programm dann noch einmal.

## Das Update klappt nicht

Liegt das Programm in einem geschützten Ordner, zum Beispiel unter „Programme“, kann es sich nicht selbst ersetzen. Das Programm zeigt dann einen Knopf zur Download-Seite. Lade dort die neue Version herunter, oder verschieb das Programm in einen eigenen Ordner, zum Beispiel in deine Dokumente.

Unter Linux und macOS gibt es keine Updates über das Programm. Dort lädst du neue Versionen von Hand herunter.
